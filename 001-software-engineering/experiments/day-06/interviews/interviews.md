Interview Question 1

What is a kernel?

Suggested answer:

The kernel is the core part of an Operating System. It manages important resources such as CPU, memory, processes, and hardware access.

---

Interview Question 2

What is a system call?

Suggested answer:

A system call is a controlled mechanism through which an application requests a service from the Operating System kernel.

---

Interview Question 3

Why can't applications directly access everything on the computer?

Suggested answer:

Restricting direct access helps protect system security and stability. Applications generally use controlled interfaces to request privileged operations from the kernel.

---

Interview Question 4

What is the difference between user mode and kernel mode?

Suggested answer:

User mode is where normal applications execute with restricted privileges. Kernel mode is where the OS kernel executes with higher privileges to manage system resources.
