Interview Question #1

What is a process?

Good beginner answer:

A process is a program that is currently running. It has its own resources, such as memory and execution state, and the operating system manages it.

---

Interview Question #2

What's the difference between a program and a process?

Simple answer:

A program is a set of instructions stored somewhere, while a process is an instance of that program currently running.

---

Interview Question #3

What does an operating system do?

Simple answer:

An operating system manages the computer's hardware and provides resources and services that applications use, including CPU, memory, storage, files, and networking.
